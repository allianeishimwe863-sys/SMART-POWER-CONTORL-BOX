About This Project

Smart electricity monitoring and remote control

Smart Power Control Box is an intelligent electricity monitoring and control system designed to help users manage electrical channels remotely through a modern web dashboard and Blynk IoT.

The system allows users to control four power channels, monitor AC voltage, current, apparent power and daily energy consumption, view system fault conditions, reset protection faults, and schedule Channel 3 to operate automatically.

Developer: Alliane Niyonizeye

This website controls Blynk Virtual Pins. Test using safe low-voltage loads before any household installation.
